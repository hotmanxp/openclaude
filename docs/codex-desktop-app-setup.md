# Codex Desktop App 安装和使用指南

> 原文: [Codex CLI 中文站](https://codexcli-china.com/docs/codex-desktop-app-anzhuang-shiyong/)
> 发布时间: 2026-03-15 · 更新于: 2026-03-25

这篇教程一步讲清 Codex Desktop App 的下载安装、API Key 配置、中文界面切换、基础使用方法与常见问题排查，适合第一次接触桌面版的用户快速上手。

---

## 一、Codex Desktop App 是什么

Codex Desktop App 是 OpenAI 提供的桌面客户端，适合在本地电脑上直接与 Codex 交互，辅助完成代码编写、改代码、排查 bug，写测试、整理文档等任务。

官方介绍页面：https://developers.openai.com/codex/app/

> 注意：国内用户通常需要先保证网络可访问，再打开官网页面。

---

## 二、Codex Desktop App 下载方法

### 1. macOS 下载方式

macOS 用户最方便，直接打开下面的链接下载安装包：

- https://persistent.oaistatic.com/codex-app-prod/Codex.dmg

### 2. Windows 下载方式

Windows 用户可以通过微软官方页面下载安装：

- https://apps.microsoft.com/detail/9plm9xgg6vks?hl=zh-cn&gl=US

打开链接后，按微软安装提示完成安装即可。安装完成后，应用通常会自动启动。

---

## 三、安装完成后为什么还不能直接用

很多人安装好后发现，软件并不能立刻使用。这通常是因为 **Codex Desktop App 还需要先配置 API Key**。

- 如果你以前已经在这台机器上使用过 **Codex CLI**，桌面版通常会直接读取已有配置。
- 如果你以前没有配置过，就需要手动设置一次。

---

## 四、如何配置 API Key

对于国内用户，很多人会选择使用中转方式。下面是示例链接：

- https://codex.dakeai.cc/register?promo=DKAI

注册并登录后，按平台引导完成：

1. 创建自己的 API 密钥。
2. 点击"使用密钥"。
3. 选择对应系统。

例如：

- **Windows 用户选择：Windows PowerShell**

然后把页面提供的脚本复制下来，按说明操作：

1. 打开 **PowerShell**。
2. 粘贴脚本并执行。
3. 完成覆盖配置。

配置成功后，重新打开 **Codex Desktop App**，随便发送一条消息测试。如果能正常回复，就说明已经可以使用。

---

## 五、如何把 Codex 桌面版切换成中文

Codex Desktop App 默认界面通常是英文，如果你想切换成中文，可以按下面步骤操作：

1. 打开软件。
2. 点击左上角 **File**。
3. 点击 **Settings**。
4. 进入 **General**。
5. 找到 **Language / Language for the app UI**。
6. 在下拉框中选择 **中文（中国）**。

切换中文时的注意事项：

- 如果切换后没生效，可能是应用需要联网下载语言包。
- 先保证网络可用，再重新进入设置切换一次。
- 必要时重启应用后再试。

## 六、完成以上两步后就可以正常使用了

当你已经完成：

- 安装 Codex Desktop App
- 配置好 API Key
- 切换好中文界面

那么你就可以正式开始使用 Codex 了。

## 七、Codex 能帮你做什么

Codex 的用途非常广，尤其适合程序员、开发者和需要处理技术文档的人。常见场景如下。

### 1. 代码相关工作

- **写代码**：根据需求实现函数、模块、脚本、前后端页面。
- **改代码**：在现有项目中添加功能、重构代码、优化性能。
- **查 bug**：阅读报错信息、日志和源码，协助定位并修复问题。
- **写测试**：补充单元测试、集成测试，并解释测试思路。
- **代码审查**：发现潜在 bug、边界情况和缺失测试。

### 2. 本地项目操作

- 查看和理解项目结构、关键文件。
- 通过命令行编译、运行测试、启动开发服务器。
- 编写自动化脚本（构建、部署或效率工具）。

### 3. 学习与解释

- 解释并发、异步、设计模式、数据结构等概念。
- 讲解项目中的代码在做什么、为什么这么写。
- 根据你的项目目标，给出更贴合实际的学习建议。

### 4. 文档与文字工作

- 编写或修改接口文档、设计文档、README。
- 润色技术说明。
- 中英文互译。
- 帮你整理需求、拆解任务、输出开发计划。

---

## 八、如何开始使用 Codex

配置完成后，直接把目标告诉它即可，例如：

- 帮我看看这个报错怎么解决。
- 在这个项目里加一个登录功能。
- 帮我把这段中文需求转成英文接口文档。
- 帮我解释一下这段代码在干什么。

你只需要给出当前最想解决的事情，Codex 就可以从那里开始协助你。

## 九、总结

总的来说，Codex Desktop App 的使用流程并不复杂，核心就是三步：

1. 下载安装客户端
2. 配置 API Key
3. 切换中文界面

完成后，你就可以把它当作本地开发助手来使用，无论是写代码、改项目、排查 bug，还是写文档、学技术，都能明显提升效率。

## 常见问题

**安装完 Codex Desktop App 后为什么不能直接用？**

通常是因为还没有配置 API Key；如果你之前已在同一台机器配置过 Codex CLI，桌面版可能会自动读取配置。

**切换中文后没有生效怎么办？**

先确认网络可用，再重新切换一次语言；必要时重启应用，让语言包重新加载。

**Windows 和 macOS 的下载方式一样吗？**

不一样：macOS 可以直接下载安装包，Windows 使用微软应用商店链接安装。
